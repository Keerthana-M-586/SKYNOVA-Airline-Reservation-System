# SKYNOVA-Airline-Reservation-System
Smart airline reservation system developed using C++ and Win32 API


Project Overview

SKYNOVA is a Smart Airline Reservation System developed using C++11 and the Windows API (Win32). It provides a graphical interface for flight searching, fare calculation, seat allocation, booking management, and e-ticket generation.

Features

- Flight search and budget-based filtering
- Dynamic fare calculation
- Buy Now or Wait Advisor
- Automatic seat allocation
- Ticket booking and cancellation
- Booking status checking
- E-ticket generation

Technologies Used

- C++
- C++11
- Windows API (Win32)
- Visual Studio

How to Run

1. Open the source code in Visual Studio on Windows.
2. Configure the project for C++11 and Windows desktop application development.
3. Build the project.
4. Run the compiled application.
